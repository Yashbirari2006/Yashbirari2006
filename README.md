# `$ problem-solving`

I'm actively improving my DSA skills through a **pattern-based approach**.

```text
                    PROBLEM
                       │
                       ↓
                 Understand It
                       │
                       ↓
                Identify Pattern
                       │
        ┌──────────────┼──────────────┐
        ↓              ↓              ↓
     Hashing      Two Pointers    Sliding Window
        │              │              │
        └──────────────┼──────────────┘
                       ↓
                Choose Approach
                       │
                       ↓
                 Write Solution
                       │
                       ↓
                  Analyze O(n)
                       │
                       ↓
                  Optimize
```

### Topics I'm working through

`Arrays` · `Strings` · `Hashing` · `Two Pointers` · `Sliding Window`

`Linked Lists` · `Stack` · `Queue` · `Binary Search`

`Trees` · `Graphs` · `Recursion` · `Backtracking` · `Dynamic Programming`

> **Goal:** Understand the pattern and reasoning behind a solution instead of simply memorizing code.
